# AC Entertainment Bot

## Deploy ด้วย PM2

ต้องใช้ Node.js 22.12 ขึ้นไป ค่า Discord ปัจจุบันและรูปอยู่ใน data/ แล้ว ไม่ต้องตั้ง Welcome/Goodbye/Ticket/Console ใหม่

```bash
git clone https://github.com/alongkon2103/ACBot.git
cd ACBot
npm ci --omit=dev
cp .env.example .env
# เปิด .env แล้วใส่ DISCORD_TOKEN ของบอท
npm install -g pm2
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
# รันคำสั่งที่ pm2 startup แสดง (สำหรับ Linux ที่รองรับ systemd)
```

ไฟล์ ecosystem ใช้ fork 1 instance เพื่อไม่ให้ตอบซ้ำ อ่าน Token จาก .env และคัดลอกค่าตั้งค่ากับรูปไป .runtime/data เมื่อรันครั้งแรก หลังจากนั้นการตั้งค่าใน Discord จะเขียนลง .runtime/data ซึ่งไม่อยู่ใน Git และไม่ถูกแทนที่ตอนอัปเดตโค้ด

```bash
pm2 status
pm2 logs acbot --lines 100
# อัปเดตโค้ด โดยเก็บค่าที่ตั้งผ่าน Discord บนเซิร์ฟเวอร์ไว้
git pull --ff-only
npm ci --omit=dev
pm2 restart ecosystem.config.cjs --update-env
pm2 save
```

สำรอง .runtime/data เป็นระยะ เมื่อต้องย้ายเครื่องครั้งต่อไปให้ย้ายโฟลเดอร์นี้พร้อม .env ด้วย อย่ารัน setup:server ซ้ำเพื่อ deploy เพราะค่าห้องและยศมีอยู่แล้ว ก่อนเปิดบนเซิร์ฟเวอร์ให้หยุดบอทที่เครื่องเก่า เพื่อไม่ให้ทั้งสองเครื่องตอบเหตุการณ์เดียวกัน

Git มี data/bot.json, data/server-setup.json และรูปใน data/assets/ เป็นค่าตั้งต้น ณ เวลาที่อัปโหลด ไม่รวม .env, node_modules, log และไฟล์สำรองสิทธิ์ห้องเก่า


Node.js 22.12+ / discord.js 14. Run `npm install`, configure `.env`, then `npm start`.
Never commit `.env`. Keep `data/` when moving or restarting the bot: it contains settings, uploaded images and ticket records.

## ตั้งค่าใน Discord

ใช้ได้โดยยศ Admin หรือผู้มีสิทธิ์ Manage Server (รวม CEO และเจ้าของเซิร์ฟเวอร์)

| คำสั่ง | การทำงาน |
|---|---|
| `/welcomeconfig` | เลือกห้อง ข้อความ รูป สี และเปิด/ปิดการต้อนรับ |
| `/goodbyeconfig` | เลือกห้อง ข้อความ รูป สี และเปิด/ปิดข้อความอำลา |
| `/ticketconfig` | ตั้งค่าแผง Ticket เลือกทีมดูแล เปิด/ปิดและส่งแผง |
| `/announce` | เขียนประกาศ ดูตัวอย่างและยืนยันส่ง |
| `/bothelp` | คู่มือใน Discord |
| `/ping` | ตรวจสถานะ |

แต่ละเมนูแสดงเฉพาะผู้ใช้งาน เลือก **ข้อความและรูป** เพื่อเปิด modal มีหัวข้อ ข้อความ สี HEX แบนเนอร์และโลโก้ รองรับ PNG/JPG/GIF/WebP ไม่เกิน 8 MB ต่อรูป เว้นช่องอัปโหลดไว้เพื่อใช้รูปเดิม หรือกดล้างรูปเพื่อลบทั้งสองรูป

แท็กข้อความ: `{user}` แท็กสมาชิก, `{username}` ชื่อผู้ใช้, `{server}` ชื่อเซิร์ฟเวอร์, `{count}` จำนวนสมาชิก ไม่มีการ ping everyone จากข้อความที่ตั้งไว้

Ticket ด้านนอกมีปุ่มสมัครเข้าสังกัดปุ่มเดียว เปิดห้องทันทีโดยไม่กรอกแบบฟอร์ม คนหนึ่งเปิดได้ครั้งละ 1 ตั๋ว ห้องเห็นเฉพาะเจ้าของตั๋ว ทีมดูแลและผู้มี Administrator กดยืนยันปิดตั๋วแล้วจะลบห้องและข้อความในห้องทันที ไม่เปลี่ยนทีมดูแลระหว่างมีตั๋วเปิดอยู่

การยืนยันประกาศจดจำข้อความและห้องในขณะที่เตรียมส่ง หมดอายุใน 10 นาทีและใช้ซ้ำไม่ได้ หากรีสตาร์ตระหว่างยืนยัน ให้เปิดเมนูใหม่

## ข้อกำหนด Discord

- เปิด **Server Members Intent** ใน Developer Portal → Bot เพื่อรับสมาชิกเข้า/ออก บอทตรวจสถานะตอนเริ่มทำงาน หากยังปิดอยู่ ระบบอื่นยังทำงานได้
- บอทต้องมีสิทธิ์จัดการห้องและกำหนด permission รวมทั้งส่งข้อความ ฝังลิงก์และแนบไฟล์ในห้องปลายทาง
- ไม่ต้องเปิด Message Content Intent สำหรับระบบเหล่านี้
- ค่าทั้งหมดและรูปอยู่ในเครื่องนี้ บอทต้องรันต่อเนื่องเพื่อรับปุ่มและเหตุการณ์
- ค่าประกาศเป็นฉบับร่างร่วมของทีมงาน แต่แต่ละการยืนยันจะส่งข้อความตามตัวอย่างที่ยืนยัน

## ตรวจสอบ

`npm run check` ตรวจ syntax, `npm test` ทดสอบสิทธิ์ การเปิด/ปิดตั๋ว การกันซ้ำ และ modal

`npm run permissions:server` ใช้ปรับสิทธิ์ห้องพื้นฐาน ไม่แก้สิทธิ์ห้อง Ticket ที่สร้างภายหลัง

## Control Console

แผงควบคุมถูกวางและปักหมุดในห้องพัฒนา มีปุ่ม Welcome, Goodbye, Ticket, ประกาศ, ข้อความ Ticket, วิธีใช้และรีเฟรช เปิดหน้าตั้งค่าส่วนตัวโดยไม่ต้องใช้ slash command สิทธิ์การตั้งค่ายังคงเป็น Admin/CEO หรือ Manage Server หน้าสรุปแสดงจำนวนสมาชิก ตั๋วที่เปิด สถานะระบบ และ uptime อัปเดตข้อความเดิมทุก 1 นาทีและหลังรีสตาร์ต

ภายใน Ticket มี 6 ปุ่ม: ติดต่อเข้าสังกัด, แจ้งบัค / ปัญหาการใช้งาน, สอบถามโบนัส / รายได้, ขอความช่วยเหลือติดตั้ง, ติดต่อแอดมิน, สอบถามข้อมูลสังกัด กดปุ่มแล้วบอทส่งข้อความในห้องให้ผู้ใช้พิมพ์ตอบได้เลย


## ข้อความตอบกลับและเว็บไซต์

ใน Console กด Ticket → ข้อความตอบกลับ เพื่อแก้คำตอบ 5 หัวข้อ หรือกด เว็บไซต์สังกัด เพื่อตั้งลิงก์ของปุ่มสอบถามข้อมูลสังกัด เว้นว่างเพื่อล้างค่า หากยังไม่ตั้งเว็บไซต์ บอทแจ้งผู้กดเป็นข้อความส่วนตัวว่ายังไม่ได้ตั้งค่า ข้อความหัวข้ออื่นแสดงในห้อง Ticket ให้ทั้งผู้สมัครและทีมดูแลอ่านได้

## แก้ไขข้อความที่ส่งแล้ว

เข้า Console → Ticket หรือ ประกาศ → แก้ไขข้อความเดิม เลือกรายการที่เคยส่ง หรือใช้ เลือกจากลิงก์ แล้ววาง Copy Message Link ของข้อความเก่า แก้หัวข้อ เนื้อหา สี แบนเนอร์และโลโก้ → ดูตัวอย่างและยืนยัน → ยืนยันอัปเดตข้อความเดิม

ข้อความยังอยู่ที่เดิมและใช้ลิงก์เดิม รูปที่ไม่เปลี่ยนจะเก็บไว้ ปุ่มเปิด Ticket ยังคงอยู่ หากต้องการเอารูปออกให้กด ล้างรูป ก่อนดูตัวอย่าง การแก้ข้อความเดิมแยกจากฉบับร่างสำหรับส่งข้อความใหม่ ประวัติข้อความที่ส่งหลังอัปเดตนี้เก็บใน data/bot.json และใช้ได้หลังรีสตาร์ต ข้อความเก่าเลือกผ่านลิงก์ได้

แก้ได้เฉพาะแผง Ticket หรือประกาศที่บอทนี้ส่งเองในเซิร์ฟเวอร์นี้ เฉพาะ Admin/CEO หรือ Manage Server ถ้ามีคนอื่นแก้ข้อความเดียวกันระหว่างเปิดหน้าตั้งค่า จะให้โหลดใหม่ก่อนเพื่อป้องกันการเขียนทับ หน้าต่างแก้ไขหมดอายุใน 30 นาที
